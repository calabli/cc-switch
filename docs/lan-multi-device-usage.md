# 多设备用量统计

两台设备安装包含此功能的版本，并保持在可互相访问的局域网中。在用量统计的「多设备同步 → 管理设备」里开启「共享本机用量」，勾选允许共享的应用，扫描或按地址连接另一台设备。默认端口为 17890。

「多设备同步」保留原页面的时间、应用、供应商、模型筛选，以及请求日志、供应商和模型视图。统计范围为本机用量，加上已启用设备最后成功同步的用量；请求日志里的状态码筛选仍按原页面的规则工作。供应商按应用与显示名称合并，模型沿用原页面的有效计价模型规则。

每台设备的应用勾选项决定它向其他设备提供哪些本机记录，不会删除本机数据。取消勾选后，对端下一次成功同步会移除对应副本。关闭某台已连接设备的同步开关，会把该设备从合计中排除，但保留已缓存的数据，重新启用后可以继续使用。

刷新沿用原页面的间隔、窗口焦点和手动同步入口。进入多设备视图后，会在本机扫描完成后拉取已登记设备的用量；连接、断开、启停设备后也会立即重查合计。对端离线或同步失败时保留最后成功同步的数据，错误不会把历史用量清零。

同步内容仅包含用量指标、供应商显示名称、模型及请求/会话标识和耗时等统计字段，不包含供应商配置、API 密钥或对话正文。费用保留发送设备记录的金额，不按接收设备的价格重新计算。远端副本不会再次导出。

旧版本设备没有完整的供应商和模型别名字段，供应商可能显示为 `Unknown provider (legacy peer)`。两端均升级后，下一次同步会自动替换旧快照，并支持完整筛选。
